# پروژه مرورگر چنداکانتی ایزوله (Moror)

یک مرورگر فوق‌سبک، بدون انیمیشن و کاملاً ایزوله برای اندروید با پشتیبانی از ورود مستقل به اکانت‌های گوگل و جیمیل بدون تداخل سشن‌ها.

---

## ویژگی‌های کلیدی

1. **ایزوله‌سازی ۱۰۰٪ سطح سیستم‌عامل (OS-Level Multi-Process Isolation):**
   - استفاده از متد نیتیو `WebView.setDataDirectorySuffix("profile_X")` در پروسس‌های تفکیک‌شده اندروید.
   - هر پروفایل/اکانت دارای پایگاه داده، کوکی‌ها، حافظه کش، LocalStorage و IndexedDB کاملاً مستقل است.
   - لاگین در اکانت جیمیل ۱ هیچ‌گونه ردپا یا تداخلی با اکانت جیمیل ۲ در پروفایل دیگر ندارد.

2. **حل مشکل لاگین گوگل (Bypass Error 403 disallowed_useragent):**
   - حذف خودکار تگ‌های بلاک‌کننده (`Version/4.0` و `; wv`) از User-Agent نیتیو.
   - فعال‌سازی کوکی‌های Third-Party جهت هدایت‌های OAuth بین دامنه‌های گوگل (`accounts.google.com`, `myaccount.google.com`).
   - فعال‌سازی کامل `domStorage` جهت نگهداری توکن‌های امنیتی جیمیل.

3. **رابط کاربری بدون انیمیشن و حداکثر سبکی (Ultra-Light & Zero-Animation):**
   - تمامی انیمیشن‌های پنجره، ترنزیشن‌ها و دیالوگ‌ها غیرفعال شده‌اند (`windowAnimationStyle = null`) تا سرعت سوییچ آنی و مصرف باتری و رم به حداقل ممکن برسد.
   - رابط کاربری فلت با تم تیره بهینه.

4. **مدیریت پروفایل‌ها (Profile Manager):**
   - ایجاد، تغییر نام، پاکسازی حافظه کش/کوکی و حذف آسان پروفایل‌ها.
   - سوییچ لحظه‌ای بین اکانت‌ها.

---

## نحوه باز کردن و اجرا در اندروید استودیو (Android Studio)

1. نرم‌افزار **Android Studio** را باز کنید.
2. گزینه **Open** را انتخاب کرده و مسیر این پروژه را انتخاب نمایید:
   ```
   c:\Users\reza\AndroidStudioProjects\moror
   ```
3. اجازه دهید فرایند Gradle Sync به صورت خودکار انجام شود (تمام تنظیمات و کش محلی پیش‌تر اعتبارسنجی شده‌اند).
4. روی کلید سبز رنگ **Run ('app')** کلیک کنید تا روی گوشی یا ایمولاتور نصب و اجرا شود.
